Uninstall Fokasu 1.0.1

Follow these three steps before installing the latest version of Fokasu.

  1. 01

    Close Fokasu

    Close the Fokasu window. Then open the application tray, right-click Fokasu, and select Exit.

  2. 02

    Start the uninstall

    Search for Fokasu in the Windows search bar. Right-click it, then select Uninstall.

  3. 03

    Remove Fokasu

    Find Fokasu in the Programs and Features window. Right-click it, then select Uninstall.

You’re ready

Install the latest version.
