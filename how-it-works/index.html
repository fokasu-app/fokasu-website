How Blocking Works

The focus lock cycle

  1. 1 Set a focus goal Setting a focus goal (like 2 hours) enables blocking.
  2. 2 Complete todos Completing todos contributes to your goal.
  3. 3 Unlock automatically Blocking ends when your focus goal is achieved.

Enable Blocking

Step 1 · Extension

Install Fokasu extension from here.

Incognito access lets Fokasu enforce your block there too. Your website data stays inside your browser and is used only for blocking.

Extension required If Focus Lock is active and the extension is not installed or enabled, Fokasu detects it and closes the browser after a grace period (60 seconds by default).
Browser support Chrome, Brave, other Chromium browsers, and Firefox are supported. Other browsers are closed while a block is active.

Step 2 · Focus goal

Open the Fokasu desktop application and click the lock icon.

Click the lock icon in the header (beside the online status information) to begin setting up your focus goal.

Step 2 · Focus settings

Set your focus time.

Choose how long you want to focus. If this is your first run, try a one-minute commitment to learn the flow.

Optional break reward Choose a percentage of each completed todo to receive as break time.

Step 3 · Lock active

The sidebar shows that your lock is running.

The progress bar begins at zero and grows as completed todo time counts toward your focus goal.

Step 4 · Block list

Add the websites you want out of reach.

Open Block from the sidebar, enter a website or keyword, then select the plus button. For example, reddit.com blocks Reddit.

Exceptions and wildcards

Use the exception list when part of a blocked website should remain available.

For example, block reddit.com, then add reddit.com/r/* as an exception.

The * wildcard matches anything that comes after /r/.

Block the entire internet

Adding only * to your block list blocks all the websites in your browser.

Set up your exception list first so the websites you need remain available.

Step 4 · Applications

Block distracting desktop applications too.

Open the Applications tab, search your installed applications, then select the checkbox beside each application you want Fokasu to block.

Step 5 · Try it

Open the site. Fokasu stops it.

The block page confirms that your focus session is active. Even if you quit Fokasu or restart your computer, the block remains enforced.

While locked You can add to the block list and remove from the exception list, but not weaken either list.

Disable Blocking

Step 6 · Create a todo

Give the todo an estimated focus time.

Create a todo from the sidebar's Create button or shortcut Ctrl + Shift + T.

Which todos count Only todos started after the focus goal is created contribute toward that goal.

Step 6 · Earn progress

Complete the todo to advance your focus goal.

Start the todo and finish its focused time. Once completed, the completed time contributes to the committed focus time.

Step 7 · Goal met

Complete your committed focus goal to unlock the block list.

Finish one one-minute todo—or two 30-second todos. Completed time adds together.

Todo complete → Focus goal met → Block list unlocked

Optional

Settings · Preferences

Fine-tune protection and application behavior.

Open Settings to adjust these optional safeguards and desktop preferences.

  • Extension activation grace period Choose how long Fokasu waits before closing the browser when the extension is not detected.
  • Prevent uninstall during a Focus Block Require the current Focus Block to finish first.
  • Emergency exit Set how long Fokasu waits before an emergency exit clears an active focus lock.
  • Desktop notifications Choose whether Fokasu shows desktop notifications.
  • Notification sounds Turn sounds during notifications on or off.
  • Start at sign-in Choose whether Fokasu starts when you sign in.
